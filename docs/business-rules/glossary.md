# Glossário operacional

| Termo | Definição AS-IS | Não significa |
| --- | --- | --- |
| Aluna | Usuária que pode receber acesso a um curso. | Um papel administrativo. |
| Curso | Conteúdo comercializável composto por módulos e aulas. | Uma matrícula. |
| Pedido | Registro de uma cobrança externa e seu estado recebido. | A autorização de acesso por si só. |
| Grant | Registro de concessão de acesso derivado de operação administrativa ou pagamento. | O evento de pagamento original. |
| Matrícula | Estado de acesso de uma aluna a um curso. | Propriedade do conteúdo. |
| Progresso | Estado de conclusão de uma aula por aluna. | Duração editorial de uma aula. |
| Duração editorial | Metadado de aula mantido pela administração. | Telemetria enviada pelo navegador. |
| Certificado | Registro emitido após os requisitos de conclusão vigentes. | Evidência de que a regra é legalmente suficiente. |

Este glossário descreve a terminologia usada pela aplicação em 2026-07-17. Mudanças semânticas exigem decisão no registro correspondente.
