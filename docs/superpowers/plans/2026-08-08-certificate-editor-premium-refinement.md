# Certificate Editor Premium Refinement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the dense certificate editor controls with a canvas-first inspector and on-demand visibility Sheet, while adding precise geometry controls, vertical text alignment, subtle asset management and a persisted certificate workload override.

**Architecture:** Keep the existing DOM-first preview and normalized percentage field spec. Move the field inventory into a Radix Sheet and keep the right side contextual to the selected field. Store workload override as a nullable `certificate_templates` column and carry the effective value through the render snapshot and PDF renderer with backward-compatible parsing.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, Radix UI primitives already present in `src/components/ui`, Drizzle/PostgreSQL, Zod, PDFKit, Vitest.
